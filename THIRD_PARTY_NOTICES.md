Font archives generated by Harf include the respective original font license. Dependencies installed by npm include their upstream license files. Runtime license texts are additionally provided in `public/notices/` for static distribution. No font license is replaced by Harf's MIT license.

Each additional distribution family records `sourceFiles` in the catalog. Those files include the original source archive, Debian packaging archive, signed source descriptor and `UPSTREAM-NOTICES.txt` with verbatim upstream licenses, authors and readme notices. These are included in family ZIP downloads. Font binaries are unmodified. The catalog retains a SHA-256 digest of the binary package; source archive sizes and SHA-256 digests are verified against the descriptor during synchronization.

Curated creator families record `curatedSource`, `licenseKind` and an Arabic design fingerprint. Source repositories are pinned to commits; direct font and Font Library archive bytes are checked against SHA-256. Original full license texts embedded in Layla and Kurinto name-table metadata are retained in external text files without changing the fonts. Where an original notice references Apache 2.0 without its full text, the complete Apache 2.0 license is included as well.

Raqq, Raqq Sura, Rana Kufi, Astrolabe, Qashib and Atiq retain their AGPL-3.0 license and corresponding source snapshots, including unmodified editable Glyphs sources and build configuration. Reference graphics and publication PDFs are omitted and listed in HARF-SOURCE-BUNDLE.txt. Editor background-image references remain unchanged; their referenced images may be obtained separately from the original repository. License notices contain text notices rather than similarly named image files. SVG exports retain the original font copyright and full license text in escaped metadata with the pinned upstream source URL. Hussaini Nastaleeq retains its original CRULP license, font embedding exception and editable FontForge source. These font licenses do not become MIT through inclusion in Harf.
